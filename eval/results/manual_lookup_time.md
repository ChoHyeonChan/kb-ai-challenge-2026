## 이 측정에서 드러난 것

### 1. 조건 7개 중 4개를 검색으로 찾았다
앱 메뉴 계층으로 도달한 사례가 없다. 실물 카드로 확인한 3건(서명·영문명·유효기한)을 빼면
**앱에서 확인해야 하는 4건 전부가 검색을 거쳤고, 그중 2건은 앱을 벗어나 KB 사이트로 나갔다.**

> 관련: 팀장(현찬)의 사전 관찰에서도 쿠폰함·해외거래정지 **2건 모두 메뉴로 못 찾고 검색으로 도달**했다.
> 서로 다른 3명, 서로 다른 기기(Galaxy·iPhone)에서 같은 패턴이 반복됐다.

### 2. 정보가 있어도 결론에 도달하지 못하는 경우가 있다
T&E 한도는 FAQ까지 도달했으나 **"고객센터에 문의하라"는 안내로 끝났다.**
→ *"확인하세요"라고 말할 뿐 확인해주지 않는다*는 문제의 실례.

### 3. ★ 자기 설정을 확인하는 데도 인증 장벽이 있다
1차 측정에서 조건 1·2는 **카드 비밀번호를 몰라 측정조차 하지 못했다.**
→ 사용자는 자신의 상태를 모를 뿐 아니라, **확인하려 해도 막힌다.**
→ 본 시스템이 판정 결과를 `unknown`으로 분류하는 설계가 현실을 반영한다는 근거.

### 4. 앱 안에서 찾은 것이 앱 밖에서 찾은 것보다 느렸다
| 위치 | 평균 |
|---|---|
| 실물 카드 (3·4·5) | 25.4초 |
| 앱 내 설정 (1·2) | **61.1초** |
| 앱 밖 검색 (6·7) | 64.0초 |

**앱에서 자기 설정을 확인하는 것이 실물 카드를 눈으로 보는 것보다 2.4배 오래 걸렸다.**

## 한계 (정직하게)

- **측정자 2명, 각 1회.** 통계적 대표성 없음. 기기·계정이 달라 단순 합산은 참고치다.
- 측정자들은 **찾아야 할 조건 목록을 미리 알고 있었다.**
  무엇을 확인해야 하는지 모르는 실제 사용자는 더 오래 걸린다 → **이 수치는 실제 소요의 하한이다.**
- 조건 1·2는 1차 측정자가 진입하지 못해 다른 사용자가 측정했다.
