# 배포 (Vercel) — 선택 사항

> **배포는 제출 필수 요건이 아니다.** 요강상 프로토타입은 *"구현 코드, GitHub 링크 대체 가능"* 이다.
> 이 문서는 심사위원이 설치 없이 눌러볼 수 있는 주소를 만들고 싶을 때만 따른다.

## 왜 Vercel 이 맞는가

| 조건 | 우리 상태 |
|---|---|
| 런타임에 비밀키가 필요한가 | **아니다.** 판정 경로는 `openai` 를 import 하지 않는다 — 키 유출 위험 0 |
| 런타임에 파일을 쓰는가 | 아니다. 조건 트리·프로필을 **읽기만** 한다 |
| 데이터 크기 | 트리 2개 + 프로필 5개, 수십 KB |
| 콜드스타트 | Python 함수 기준 1~2초. 무료 컨테이너형 호스팅(30초대)보다 낫다 |

> 추출 파이프라인(LLM 호출)은 **오프라인 1회성**이라 배포본에 들어가지 않는다.
> 배포되는 것은 **판정 엔진 + 데모 화면**뿐이다.

## 준비된 것

```
pyproject.toml   [tool.vercel] entrypoint = "src.api.main:app"
                 (Vercel 은 app.py/index.py/main.py 를 자동 탐색하는데
                  우리 앱은 src/api/main.py 라 탐색 범위 밖이다)
vercel.json      함수 번들에 data/trees·data/profiles·web 을 포함시키고
                 수집 원문·청크·캐시·문서는 제외한다
```

**둘 다 로컬 실행에는 영향이 없다.** `./run.sh` 는 그대로 동작한다.

## 절차 (현찬)

1. https://vercel.com 에 **GitHub 계정으로 로그인**
2. **Add New… → Project** → `kb-ai-challenge-2026` 선택
   - private 저장소도 배포된다. **저장소가 공개로 바뀌지 않는다**
3. Framework Preset: **Other** (자동 감지되면 그대로)
   Root Directory: **`/`** (저장소 루트가 곧 앱이다)
4. Environment Variables: **비워 둔다.** 판정에는 키가 필요 없다
5. **Deploy**

## 배포 후 3분 점검 — 이것만 확인하면 된다

| # | 확인 | 정상 |
|---|---|---|
| 1 | `/api/goals` 를 연다 | 목표 2개가 JSON 으로 나온다. **`[]` 면 실패** (아래 참고) |
| 2 | `/` 를 연다 | 판정 결과가 이미 떠 있다 (빈 화면이 아니다) |
| 3 | 조건 트리를 펼친다 | 조건 11개가 보인다 |
| 4 | 근거 `원문 열기 ↗` | KB 페이지로 이동한다 |

### `/api/goals` 가 `[]` 로 나오면

함수 번들에 `data/` 가 안 들어간 것이다. `vercel.json` 의 `includeFiles` 를 넓힌다.

```json
"includeFiles": "{data/**,web/**}"
```

그래도 안 되면 배포를 포기하고 **데모 영상으로 대체한다.** 마감 전에 붙잡고 있을 일이 아니다.

## ⚠️ 마감 관련 주의

- **8/2 제출 이후에는 push 하지 않는다.** *"참가접수기간 이후 수정·변경 이력 확인 시 심사 대상 제외"* (공식 FAQ)
- Vercel 은 push 할 때마다 자동 재배포된다 → **제출 후 push 금지 규칙이 곧 재배포 금지**다
- 제출 전에 배포를 끝내고, 그 URL을 제출물에 적는다

## 배포하지 않기로 한다면

그대로 두어도 된다. `pyproject.toml` 과 `vercel.json` 은 로컬 실행을 방해하지 않는다.
제출물에는 GitHub 링크 + 실행 방법(`README.md`) + 재현 절차(`REPRODUCE.md`)로 충분하다.
