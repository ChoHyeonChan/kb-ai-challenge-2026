## 원칙

- **숨기지 않는다.** 신고표는 감점 항목이 아니라 기재 항목이다.
- 사람이 판단·검증한 부분과 AI가 생성한 부분을 구분해서 적는다.
- 조건 추출 파이프라인의 LLM 호출은 **결과물 생성 수단**이므로 '데이터 분석'에 기재한다.
- **판정 엔진에는 LLM이 쓰이지 않는다** — 이건 설계상 사실이므로 문서에도 명시한다.
